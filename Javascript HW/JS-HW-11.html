Basic user system

You are building a basic user system. Each user has a name, age, and email. Your task is to: Create a User class that stores these values. Use getter methods to access name and age. Use a setter method to safely update the email (only allow setting if the email contains an @ symbol). Use the this keyword correctly in all functions. Create an object from the class, try updating the email using both a correct and incorrect format, and print out all the user details using getter methods.
