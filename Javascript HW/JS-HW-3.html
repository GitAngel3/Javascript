Your task is to: Create an object userProfile with properties: username (e.g., " CoolUser99 ") bio (e.g., " I LOVE coding! JavaScript is Great!!! ") Create a function cleanUserBio(profile) that: Trims and converts the username and bio to lowercase Replaces all occurrences of "javascript" with "JS" Counts the total number of characters in the bio after cleanup Returns a new object with cleaned username, cleaned bio, and the bio length. Output the final result using console.log.
