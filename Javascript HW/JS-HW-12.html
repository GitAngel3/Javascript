Feedback Page

Create a simple feedback web page that includes: A form with: A text input for the user's name A textarea for their feedback A submit button When the form is submitted: The input values (name and feedback) should display on the same page without refreshing. A confirmation message (e.g., “Thanks for your feedback!”) should be shown in green. After 5 seconds, the confirmation message should disappear automatically. When the mouse hovers over the feedback display, the text should turn blue. When the mouse leaves, it should return to black.
